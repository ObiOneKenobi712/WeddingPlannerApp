# WeddingPlannerApp
Celem projektu jest stworzenie aplikacji internetowej wspomagającej organizację wesela. System ma
umożliwiać zarządzanie listą gości, budżetem, harmonogramem przygotowań oraz usługodawcami
związanymi z organizacją wydarzenia.
Projekt zostanie wykonany w technologii ASP.NET Core MVC z wykorzystaniem języka C#, Entity
Framework Core oraz bazy danych SQLite lub SQL Server.
